# 0.4.0 — 2026-09-22

## Features

- **上游同步**：手工搬运上游 `48271133` 与 `75810042` 两个批次里外科手术式的修复
  ——压缩重试不再把 TPM 429 误判为上下文溢出；长任务计时显示进位到小时，不再停在
  分钟；CJK 与色深渲染测试引入固定色深机制。`SOURCE_REV` 仍为 `72a61251`。
- **依赖对齐**：`quick-xml` 对齐上游 0.41，`tikv-jemalloc` 对齐 0.7。
- **用户指南中文化**：补完 20 篇纯英文章节，正文标题、`docs.rs` 文档名与目录条目
  统一为中文名；删除本分叉不存在的 Grove、`grok clone`、浏览器登录与 Terminal 主题
  章节；`/login`、`/logout` 按本分叉的兼容桩行为如实改写。
- **校验器自纠**：`--fix-anchors` 重写锚点多加一个右括号（15 篇 55 处，`--links`
  看不见）；`links` 判据与它自己规定的收尾动作自相矛盾；`--glob` 匹配不到文件时
  静默全 0 通过。三处均修并各加自测。
- **中文化机器校验**：新增 `scripts/check-doc-l10n.py` 与 51 条自测，把围栏代码块、
  行内代码 span、表格结构、链接目标、标题层级、正文数字、上游旧名都做成不变量；
  新增表格单元格词典，一次决定重复出现的短单元格；`doc-span-removals.tsv` 声明
  本分叉有意删除的行内字面量（15 条），删功能说明不再误报漂移。
- **应用内文案**：快捷键详情页 42 条 `long_help`、弹窗底栏 30 个快捷键标签，以及
  `stash`、`Shell` 两个条目改说中文；键位名（`Ctrl+P`、`j/k`）与命令名保持 ASCII。
- **应用内文档**：`/docs` 与教程目录改说中文；扩展管理器的标签页名称按分叉实际
  显示的中文标签对齐。

- 恢复类与诊断类提示改说中文，并清掉二进制自称 `grok` 的残留。

  `xai-grok-shell` 联动。
