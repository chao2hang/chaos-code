# Security Policy

Report security vulnerabilities privately through GitHub Security Advisories:

https://github.com/chao2hang/chaos-code/security/advisories/new

Do not open public GitHub issues for security reports.

> Note: this project is a fork. Do **not** send reports about Chaos to xAI's
> HackerOne program — they do not maintain this code and cannot act on them.
> Only report upstream if you have confirmed the issue also affects upstream
> `grok`.
